# 08 — Launch, ops, metrics

## Decisions made
- **Channel name:** Little Banyan Stories (check handle availability on YouTube before registering).
- **Language:** English narration/dialogue; Sanskrit/Hindi words as vocabulary with on-screen meanings.
- **Voices:** open-source Kokoro, one distinct soft voice per character (`pipeline/voices.json`); human voice for shlokas if the owner records.
- **Art:** 2.5D layered illustration in Remotion first (placeholder vector characters now; final character art to follow); soft-3D Blender renders later (docs/09).
- **Length:** 5–10 min per episode.

## Setup checklist
Brand account → channel name/handle → channel default "made for kids" → banner/avatar → playlists by track and value →
About text with promise "slow, calm, parent-approved" → Google Search Console-style keyword list → website for printables.

## Publishing times
Use Metricool `getBestTimeToPostByNetwork` once connected. Starting guess: 6:30–7:30 am IST (morning routine) and
5–6 pm IST; US diaspora 5 pm ET.

## Metrics (parent-friendly, not addiction metrics)
Track: completion rate, repeat views of the same episode (learning), returning viewers, shares to family chats,
playlist starts, printable downloads, parent survey (3 questions: "Did your child do the action? Calmer after? Would you recommend?").
Do **not** optimise for watch-time at all costs or session length.

## 90-day roadmap
- **Days 1–14:** character bible, style test, 7 pilot episodes, scholar review, channel setup.
- **Days 15–30:** 3–4 uploads/week; build Remotion template; collect parent feedback (10 families).
- **Days 31–60:** move to daily with a 10-episode buffer; add Hindi track; first printable pack.
- **Days 61–90:** review analytics; double down on top-2 tracks; test sponsors/products; consider long compilations ("30-minute calm story hour" with built-in breaks).
