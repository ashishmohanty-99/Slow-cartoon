# 07 — Pre-publish gate (every episode)

**Content**
- [ ] One value, one idea; ends with a real-world action
- [ ] Source named (text + chapter) and story is faithful; any adaptation flagged in description
- [ ] No fear/violence/gore, no punishment imagery, no weapons in toddler track
- [ ] No stereotypes (caste, gender, region, religion); no "other faiths are wrong"
- [ ] Sanskrit correct (shloka text, diacritics, meaning) — second pair of eyes
- [ ] Age band stated and honest (don't label 4–5 content as 2–3)

**Slow style**
- [ ] Avg shot ≥ target; no flashes; music below voice; no stingers
- [ ] 5 s silence pause after the question; soft ending; no "watch next" bait

**Technical / YouTube**
- [ ] "Made for kids" set to YES; comments off is expected
- [ ] Altered/synthetic disclosure answered per current rule
- [ ] Captions (SRT) checked; thumbnail calm; title parent-friendly; description has parent layer
- [ ] Music/art/voice licences recorded in `episodes/<id>/credits.md`
- [ ] Character matches bible (no drift)

**Originality (anti-"slop")**
- [ ] This story/plot is not a near-duplicate of the previous 5
- [ ] A human has edited the script and approved art and voice
