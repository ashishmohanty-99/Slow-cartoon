# 04 — Faceless production pipeline

```
Idea backlog ─► Script (LLM draft → human edit → source check) ─► Storyboard (6–12 key scenes)
   ─► Art (locked character bible; illustrate scenes) ─► Voice (TTS or recorded)
   ─► Timing (word timestamps) ─► Animate (parallax / limited animation / lip-flap)
   ─► Compose (Remotion or ffmpeg) ─► Subtitles + metadata ─► QA checklist (doc 07)
   ─► Schedule (Metricool / YouTube Studio) ─► Analytics review weekly
```

## Recommended stack (pick one lane; start with Lane A)
**Lane A — Remotion "illustrated storybook" (best for slow style, fully scriptable, daily-capable)**
- Art: scenes drawn once per story (hand-illustrated, Figma/Canva/Krita, or an image model with a *fixed
  character reference sheet*). Layered PNGs (background / mid / character) → Remotion gives gentle parallax,
  blinks, head-bob, text reveals.
- Voice: recorded human narration (best trust signal) or open TTS (Piper / Kokoro) for drafts.
- Captions/timing: whisper.cpp word timestamps → drive scene changes and subtitles.
- Mouth movement: optional Rhubarb lip-sync → 3–5 mouth sprites.
- Output: 1080p MP4 + SRT + thumbnail PNG, all generated by one `npm run render -- episodes/epXXX`.

**Lane B — Traditional 2D (highest quality, slower):** OpenToonz / Synfig / Pencil2D for hero episodes,
weekly "special" (festival, Ramayana arc).

**Lane C — Generative video clips (use sparingly):** Wan2.2, LTX-Video, Open-Sora via ComfyUI for short
establishing shots (clouds, river, diya flame). Character consistency and "uncanny" artefacts are risky for kids;
never let a model improvise story content.

## Daily operating rhythm (you + me)
- Mon: approve week's 7 scripts (batch). Tue–Wed: art + voice batch. Thu: render + QA. Fri: schedule next week.
- I draft scripts, metadata, descriptions, parent guides, calendars, QA reports; build/maintain the
  Remotion project; schedule posts. You: final creative approval, voice, cultural/scholar spot-check, the YouTube
  account actions that need your login.

## Buffer rule
Never publish the same day you render. Keep ≥ 7 finished episodes in the queue before moving to daily.

## What I can't do from here
Upload to YouTube directly requires your channel connected (Metricool or YouTube Studio). Image/voice
generation tools need keys/hardware you choose. See "Open decisions" in doc 08.
