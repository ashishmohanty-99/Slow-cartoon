# 03 — Slow-cartoon style guide ("slow" in numbers)

| Element | Rule |
|---|---|
| Average shot length | ≥ 8 s (2–3 yrs ≥ 12 s) |
| Camera | Slow pans/zooms ≤ 3%/s; no whip, shake or fast zooms |
| Frame rate | 12–15 fps "limited animation" is fine and calm; hold poses |
| Flashing | None. Nothing > 3 flashes/second (photosensitivity), avoid high-contrast strobing |
| Colour | Warm, soft, mid-saturation; avoid neon; bright accents only for the learning object |
| Music | Instrumental (tanpura, flute, veena, soft piano), ≥ 12 LU below voice, no sudden changes |
| Sound effects | Sparse, natural (birds, water, bell). No stingers/whooshes |
| Narration | 110–130 words/min, clear Indian-neutral English; Hindi/other tracks same pacing; pauses of 1–2 s after key lines |
| Text on screen | Max one short line; large; Devanagari + transliteration + meaning for shlokas |
| Characters | Round, friendly; no scary faces; villains (Ravana, Kamsa) shown through story not gore; no weapons in toddler tracks |
| Thumbnails | Calm illustration + short title. No red arrows, shocked faces, ALL CAPS |
| Titles | Parent-friendly: "Chintu Learns to Say Thank You | Gratitude Story for Kids (Age 4–5)" |
| End | Soft fade, "Time to play" card, 5 s of quiet. Never autoplay bait |

Visual identity: hand-painted watercolour/paper-cut look, consistent palette per track (Seedlings: sunrise yellow,
Sprouts: leaf green, Saplings: teal, Young Trees: deep indigo). Build a locked **character bible** (turnarounds,
expressions, palette hex codes) before episode 1 — consistency is what separates a brand from "AI slop".
